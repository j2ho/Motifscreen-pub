# Input Features

## Overview

MotifScreen-Aff takes two inputs per sample: a receptor (protein) graph and a ligand graph. Both are DGL graphs with node features, edge features, and 3D coordinates. The receptor graph also contains grid nodes representing the binding site.

Source files:
- Featurization: `src/io/protein_featurizer.py`, `src/io/ligand_processer.py`
- Dataset: `src/data/dataset_jiho.py`
- Type definitions: `src/data/types.py`
- Utilities: `src/data/utils.py`

---

## 1. Receptor

### 1.1 Protonation and Atom Typing

PDB files are pre-protonated externally using **Rosetta** (`score_jd2 -no_optH false`). The featurizer reads the protonated PDB and assigns atom types via the **Rosetta parameter database** (`/applic/Rosetta/database/chemical/residue_type_sets/fa_standard/residue_types`).

Atom typing is two-stage:

1. **Rosetta types** (20 types): e.g., `CAbb`, `aroC`, `Nbb`, `OCbb`. Mapped from (residue, atom_name) pairs via a hardcoded dictionary in `src/data/types.py:atypes`.

2. **Generalized types** (65 types): Rosetta types are converted via `fa2gentype()`. This is the representation used in the model. Full mapping in `src/data/types.py:gentype2num`:

```
Carbons (15):  CS, CS1, CS2, CS3, CD, CD1, CD2, CR, CT, CSp, CDp, CRp, CTp, CST, CSQ
Hydrogens (3): HO, HN, HS
Nitrogens (13): Nam, Nam2, Nad, Nad3, Nin, Nim, Ngu1, Ngu2, NG3, NG2, NG21, NG22, NG1
Oxygens (10):  Ohx, Oet, Oal, Oad, Oat, Ofu, Ont, OG2, OG3, OG31
Sulfur/P (8):  Sth, Ssl, SR, SG2, SG3, SG5, PG3, PG5
Halogens (8):  Br, I, F, Cl, BrR, IR, FR, ClR
Metals (8):    Ca2p, Mg2p, Mn, Fe2p/Fe3p(=60), Zn2p, Co2p, Cu2p, Cd
```

### 1.2 Pre-computed Files

**prop.npz** (per target, generated by `featurize_target_properties()`):

| Array | Shape | Description |
|-------|-------|-------------|
| `xyz_rec` | (N_atoms, 3) | Cartesian coordinates from protonated PDB |
| `atypes_rec` | (N_atoms,) | Generalized atom type strings (e.g., 'CS1', 'Oad') |
| `aas_rec` | (N_atoms,) | Amino acid type index (0-33) |
| `charge_rec` | (N_atoms,) | Partial charges from Rosetta params |
| `sasa_rec` | (N_atoms,) | Normalized solvent-accessible surface area (0-1) |
| `bnds_rec` | (N_bonds, 2) | Covalent bond pairs (atom indices) |
| `atmnames` | (N_atoms,) | PDB atom names ('CA', 'CB', ...) |
| `reschains` | (N_res,) | Residue chain identifiers |
| `atmres_rec` | (N_atoms,) | Per-atom residue info tuples |
| `repsatm_idx` | (N_reps,) | Representative atom indices (CA per residue) |
| `occl` | (N_atoms,) | Occlusion factor: exp(-d^2/6) summed over neighbors |
| `residue_idx` | (N_atoms,) | Original residue index |

Residue types (34 total, `N_AATYPE = 34`):
```
Index 0:      UNK (unknown/unrecognized residue)
Indices 1-20: Standard amino acids
              ALA, ARG, ASN, ASP, CYS, GLN, GLU, GLY, HIS, ILE,
              LEU, LYS, MET, PHE, PRO, SER, THR, TRP, TYR, VAL
Indices 21-25: Nucleic acid bases
              21=ADE (adenine), 22=CYT (cytosine), 23=GUA (guanine),
              24=THY (thymine), 25=URA (uracil)
Indices 26-33: Metal ions (represented as single-atom residues)
              26=CA (calcium), 27=ZN (zinc), 28=MN (manganese),
              29=MG (magnesium), 30=FE (iron), 31=CD (cadmium),
              32=CO (cobalt), 33=CU (copper)

In practice: only 20 AAs + CA (calcium) appear in training data.
Nucleotides, UNK, and metals other than CA are never observed (always-zero one-hot channels).
```

SASA is computed with 50 Fibonacci-sphere probe points at 1.4 A probe radius (`src/data/utils.py:sasa_from_xyz`).

**grid.npz** (per target, generated by `grid_from_xyz()` + `motif2label()`):

| Array | Shape | Description |
|-------|-------|-------------|
| `xyz` | (N_grid, 3) | Grid point coordinates |
| `name` | (N_grid,) | Grid point names ('grid0000', ...) |
| `labels` | (N_grid, 6) | Soft motif labels per grid point |

Grid generation: 3D mesh at 1.5 A spacing within 10.0 A of ligand, excluding points <1.1 A from receptor atoms (clash filter), restricted to largest connected component.

### 1.3 Motif Labels

6 columns in `labels`, indexed 0-5:

| Index | Name | Detection criteria |
|-------|------|--------------------|
| 0 | (unused) | Always zero |
| 1 | Both (donor+acceptor) | Ligand atom in receptor D contact (<3.6 A, cos>0.26) AND A contact |
| 2 | Acceptor | Ligand atom in receptor A contact only |
| 3 | Donor | Ligand atom in receptor D contact only |
| 4 | Aliphatic | Ligand CH2/CH3 in receptor hydrophobic contact (<5.1 A) |
| 5 | Aromatic | Ligand aromatic atom in receptor aromatic contact (<5.1 A) |

Labels are soft (not binary): `label = sqrt(exp(-d^2 / sigma^2))` where d = distance from grid point to motif center, sigma = 1.0 A.

### 1.4 Receptor Graph Construction

`GraphBuilder.build_receptor_graph()` in `dataset_jiho.py`:

**Coordinate centering**: all coordinates shifted so grid centroid = origin.

**Node selection**: KD-tree ball query at `ball_radius` (default 8.0 A, randomly perturbed +/-`ball_radius_var` during training) around grid points. Selects all receptor atoms + grid points within range. Max: 3000 nodes.

**Node features** (102 dimensions):

| Channels | Dim | Description |
|----------|-----|-------------|
| 0-33 | 34 | Residue type one-hot: 20 AAs + 5 nucleotides + 8 metals + UNK (grid nodes = UNK). In practice only 21 channels active (20 AAs + CA); rest always zero. |
| 34-98 | 65 | Generalized atom type one-hot (grid nodes = index 0) |
| 99 | 1 | Normalized SASA (grid nodes = 0) |
| 100 | 1 | Partial charge (grid nodes = 0) |
| 101 | 1 | Distance-to-origin (currently **always 0**, dead feature) |

**Edge construction**: distance-based neighbors within `edgedist[1]` = 4.5 A (mode `dist`), or k=16 nearest neighbors (mode `topk`). Within-receptor edges are forced to connect (all receptor-receptor pairs within cutoff). Max: 100,000 edges.

**Edge features** (3 dimensions):

| Channel | Description |
|---------|-------------|
| 0 | Covalent bond flag (1 if bonded in PDB, 0 otherwise) |
| 1 | Grid-grid flag (1 if both endpoints are grid nodes) |
| 2 | Sigmoid distance: `1 / (1 + exp(-m * (d - d0)))` where d0=2.25, m=2.22 |

The `_distance_feature()` function outputs `feat.repeat(1, 3)` producing 3 identical copies, then channels 0 and 1 are overwritten with bond and grid-grid flags.

**Graph tensors**:
- `graph.ndata['attr']`: (N_selected, 102) float -- node features
- `graph.ndata['x']`: (N_selected, 1, 3) float -- 3D coordinates
- `graph.edata['attr']`: (N_edges, 3) float -- edge features
- `graph.edata['rel_pos']`: (N_edges, 3) float -- relative position vectors (dX)

## 2. Ligand

### 2.1 Mol2 Parsing

Ligands are read from mol2 files via `src/data/utils.py:read_mol2()`. Hydrogen atoms are dropped by default (`drop_H=True`). The mol2 file contains Gasteiger partial charges and Sybyl atom types.

Mol2 parsing extracts:
- `elems`: element symbols mapped to `ELEMS = ['Null','H','C','N','O','Cl','F','I','Br','P','S']`
- `qs`: partial charges (from mol2 last column)
- `bonds`: covalent bond pairs (0-indexed)
- `borders`: bond orders (`1`=single, `2`=double/amide, `3`=triple/aromatic, `0`=dummy)
- `xyz`: 3D coordinates
- `nneighs`: (N, 4) neighbor counts by element [H, C, N, O] per atom
- `atypes`: Sybyl atom type strings (e.g., 'C.ar', 'N.am', 'O.3')

### 2.2 Keyatom Generation

BRICS decomposition (`define_keyatoms.py:frag_from_pdb()`) fragments each ligand at retrosynthetically meaningful bonds. One representative atom per fragment becomes a keyatom. Stored as `{ligand_tag: [atom_name_1, atom_name_2, ...]}` in `.keyatom.def.npz`.

Keyatoms serve two purposes:
1. **Structure prediction**: model predicts 3D coordinates of keyatoms
2. **Screening**: ligand-to-key mapping reduces the full ligand graph to fragment representatives for the interaction module

### 2.3 Ligand Graph Construction

`GraphBuilder.build_ligand_graph()`:

**Edge construction**: same modes as receptor, using `edgedist[0]` = 2.2 A or k=8 nearest neighbors.

**Node features** (18 dimensions):

| Channels | Dim | Description |
|----------|-----|-------------|
| 0-3 | 4 | Normalized neighbor counts [H, C, N, O], divided by total |
| 4 | 1 | Normalized SASA (computed on the fly) |
| 5 | 1 | Occlusion factor |
| 6 | 1 | Partial charge (Gasteiger, from mol2) |
| 7-17 | 11 | Element one-hot over ELEMS = [Null, H, C, N, O, Cl, F, I, Br, P, S] |

Note: Sybyl atom types (`atypes`) are passed to `_compute_ligand_node_features()` but **not used** in node feature construction. They are only used in global features for aromatic atom counting.

**Edge features** (5 dimensions):

| Channel | Description |
|---------|-------------|
| 0 | Bond order = 0 (no bond) one-hot component |
| 1 | Bond order = 1 (single) |
| 2 | Bond order = 2 (double/amide) |
| 3 | Bond order = 3 (triple/aromatic) |
| 4 | 1 / (topological_distance + 1e-5), where topological distance = shortest bond path |

Initially `edge_features = eye(5)[bond_orders]`, then channel 4 is overwritten with inverse topological distance.

**Global features** (19 dimensions, attached as `graph.gdata`):

| Channels | Dim | Description |
|----------|-----|-------------|
| 0-9 | 10 | Number of rotatable bonds, one-hot (capped at 9) |
| 10-12 | 3 | Kappa shape indices (normalized: (k1-40)/40, (k2-15)/15, (k3-10)/10) |
| 13 | 1 | Acceptor count (N/O without H neighbors, scaled by 0.2, offset -1) |
| 14 | 1 | Donor count (N/O with H neighbors, scaled by 0.2, offset -1) |
| 15 | 1 | Aromatic atom count (Sybyl types C.ar/C.aro/N.ar, normalized: (n-6)/6) |
| 16-18 | 3 | Principal moments of inertia (sqrt(eigenvalues) of inertia tensor, normalized: (v-20)/20) |

**Graph tensors**:
- `graph.ndata['attr']`: (N_atoms, 18) float -- node features
- `graph.ndata['x']`: (N_atoms, 1, 3) float -- 3D coordinates
- `graph.ndata['Y']`: (N_atoms, 3) float -- initialized to zeros
- `graph.edata['attr']`: (N_edges, 5) float -- edge features
- `graph.edata['rel_pos']`: (N_edges, 3) float -- relative position vectors
- `graph.gdata`: (19,) float -- global molecular descriptors

## 3. Keyatom Index Tensor

For each ligand in the batch, keyatom indices are encoded as a (K, N) binary matrix where K = number of keyatoms, N = number of ligand atoms. Entry (k, j) = 1 if atom j belongs to keyatom k's fragment. This tensor maps ligand atom embeddings to keyatom-level representations via `h_key = einsum('bkj, bjd -> bkd', key_idx, h_lig)`.

| Parameter | Value | Where |
|-----------|-------|-------|
| Grid spacing | 1.5 A | `receptor_features.py` |
| Grid padding | 10.0 A | `receptor_features.py` |

| Ligand edge k | 8 | `config.graph.edgek[0]` |
| Max nodes | 3000 | `config.graph.maxnode` |
| Max edges | 100000 | `config.graph.maxedge` |
| Motif label sigma | 1.0 A | `featurize_merge.py` |
| Donor/Acceptor cutoff | 3.6 A | `featurize_merge.py` |
| Donor angle threshold | cos > 0.2588 (~75 deg) | `featurize_merge.py` |
| Aromatic/Aliphatic cutoff | 5.1 A | `featurize_merge.py` |
| SASA probe radius | 1.4 A | `utils.py` |
| SASA probe points | 50 | `utils.py` |
